## What Juno Is Doing

Semi autonomous AI agent to synthesize the data from slack, tickets, sales, notes, and emails

## Four Levers

**Stop Conditions** (Loop):

Run weekly on a schedule and on demand by the PM.

**Structured Tool Outputs** (Tools):

Provide read connectors for CRM, roadmap, ticketing, capacity notes and an allowlist of Slack channels, each using read-only credentials.
Log every tool call with inputs, outputs, duration and run ID.

**Confidence Thresholds** (Verification):

When sources conflict, report both versions with their sources and ask the PM, rather than reconciling silently.
Scan every draft before the PM sees it for unscoped promises (dates, scope, capacity language) and other customers' identifying details.

**North Star** (Context):

Juno can collect data from different channels and submit the report. Don't make decision based on the report

## Rules of Engagement

**Agency Permission:**

Juno can collect data from different channels and submit the report.
Don't make decision based on the report

**Access Control:**

It can reach out to Outlook, slack, Tickets logger tool, Sales Notes app.

**Fallback Protocols:**

If the connection failure with any of the source exceed 5 tries, it should stop fetching the data

**Checkpoints:**

If it cant connect to any of the tools, notify human PM and Infrastructure team.
